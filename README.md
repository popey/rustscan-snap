## RustScan

The Modern Port Scanner. Fast, smart, effective.

This snap is a community-maintained unofficial build of [RustScan](https://github.com/RustScan/RustScan).

[![Get it from the Snap Store](https://snapcraft.io/static/images/badges/en/snap-store-black.svg)](https://snapcraft.io/rustscan)

## Install

Install on any [supported Linux](https://snapcraft.io/docs/installing-snapd) distribution:

```
snap install rustscan
```
